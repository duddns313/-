# 호그와트 7년

해리 포터와 같은 해(1991년)에 길 건너 소꿉친구 **이호현**과 함께 그리핀도르에 입학한 **윤영운**이 되어, 원작의 호그와트 7년을 사건 카드로 겪는
텍스트 어드벤처입니다. 서울 2033 · 모험가 이야기처럼 사건이 끊임없이 터지고, 능력·소지품·주문·
**예전의 선택(기억)**에 따라 선택지와 결과가 달라집니다. (개인적·비상업적 팬 프로젝트)

> 현재 **1학년(마법사의 돌) 시험판**입니다. 기획 전체는 [`docs/GAME_PLAN.md`](docs/GAME_PLAN.md)를 보세요.

## 실행

`index.html`을 브라우저로 열거나:

```
python3 -m http.server 8080   # → http://localhost:8080
```

GitHub Pages에 올리면 휴대폰 홈 화면에 앱처럼 설치해 오프라인으로도 할 수 있습니다.

## 1학년 시험판에 들어 있는 것

- **프롤로그 12장면** — 같은 날 마주 본 두 가게(윤씨네 식품점·서울 마트)에 날아온 두 장의 편지, 10년 만에 한 식탁에 앉은 두 엄마, 다이애건 앨리, 9와 3/4 승강장, 호그와트 특급(호현의 "선"), 분류 모자, 그리핀도르 탑의 첫날 밤
- **관계 연작** — 호현(신뢰가 쌓이면 자기 이야기를 꺼낸다), 헤르미온느(질문 공책), 론(체스·물려받은 것들·거울), 해리(계단 밑 벽장·빗속 연습·투명 망토). 호감도가 오를수록 다음 이야기가 열린다. 인물 설계는 [`docs/CHARACTERS.md`](docs/CHARACTERS.md)
- **정사 사건** — 첫 수업 주간, 스네이프의 마법약, 비행 수업(기억구슬), 핼러윈 트롤(화장실·교수에게 알리기 등 여러 길), 첫 퀴디치, 크리스마스(남기/집에 가기) · 소망의 거울, 150점, 금지된 숲 벌칙(주목도가 높을 때만), 기말시험, 퀴렐의 정체 맞추기(모은 단서에 따라 달라짐), 기숙사컵, 귀향
- **장소 사건 40여 개** — 12번의 턴마다 행선지 카드 3장 중 하나를 골라 그 장소의 사건을 만납니다. 피브스, 움직이는 계단과 4층 복도, 자정의 결투, 해그리드와 노버트, 대왕오징어, 주방의 집요정, 울보 머틀, 독수리 문고리 수수께끼(연속 도전), 빗자루 연습(연속 도전) 등
- 한 회차에 만나는 사건은 전체의 절반 정도라, 다른 기숙사·다른 선택으로 다시 할 이유가 있습니다.

## 시스템

| | |
|---|---|
| 스탯 5 | 🦁 용기 · 🦅 지혜 · 🦡 성실 · 🐍 기지 · ✨ 마법 — 선택지마다 다른 스탯, 성공률 미리 표시 |
| 성장 | 선택할 때마다 경험(실패하면 더 많이). 단계가 오르면 **능력치를 직접 고른다**. 판정에 쓴 능력치가 그 자리에서 오르지 않아 한 능력치만 키우는 플레이를 막는다 |
| 고집 페널티 | 최근 세 번 안에 같은 능력치로 판정하면 🔁 감점, 오래 안 쓴 능력치는 ✨ 가점 |
| 잠긴 길 | 기억·소지품·주문·관계가 모자라면 선택지가 🔒로 보이고 무엇이 필요한지 알려 준다. 열린 길에는 무엇 "덕분에" 열렸는지 표시 |
| 자원 5 | ❤️ 체력 · 💗 마음 · 🪙 갈레온 · 👁️ 주목도 · 🏆 기숙사 점수 |
| 판정 | 대성공 / 성공 / 실패 / 대실패. 실패도 다른 이야기로 이어짐 |
| 열쇠 | 주문(루모스·윙가르디움 레비오사·알로호모라 등) · 소지품 · 기억 · 관계가 전용 선택지와 보정을 연다 |
| 수집 | 개구리 초콜릿 카드 16종, 기억, 인물 관계 |
| 접근성 | 타자 속도 4단계, 연출 줄이기(기본 켜짐), 글자 크기 3단계, 양피지/밤 테마, 화면을 누르면 바로 전부 표시 |

## 파일 구조

```
index.html · css/style.css · manifest.json · sw.js
js/data/meta.js           스탯·자원·기숙사·장소·주문·소지품·인물·카드·기억·달력
js/data/year1/*.js         1학년 사건 (prologue · canon_autumn · canon_spring · places_castle · places_grounds)
js/core/                   state(저장) · rules(조건·판정·효과) · game(턴·행선지·진행) — DOM 없음
js/ui/                     settings · ui(화면)
tools/validate.js          사건 데이터 검증 (참조 오류, 렌더 오류, 같은 스탯만 쓰는 선택지, 표기)
tools/simulate.js          무작위 자동 플레이 N회 — 완주율, 사건 노출률
```

사건을 추가하거나 고친 뒤에는 `node tools/validate.js && node tools/simulate.js`로 확인하세요.
