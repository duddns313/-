# 호그와트: 그림자의 잔영

서울 2033, 모험과 이야기류의 한국형 텍스트 RPG 구조(스탯 관리·탐험·전투·상점·분기 스토리)를
해리포터 세계관 위에 얹은 브라우저 텍스트 게임입니다. 서버 없이 정적 파일만으로 동작하며, PWA로
홈 화면에 설치해 오프라인으로도 플레이할 수 있습니다. (개인적·비상업적 팬 프로젝트)

## 실행 방법

`index.html`을 브라우저로 열면 바로 플레이할 수 있습니다. (모바일 브라우저 권장 — 하단 탭 UI가 모바일 화면에 맞춰져 있습니다)

```
python3 -m http.server 8080
# 이후 브라우저에서 http://localhost:8080 접속
```

GitHub Pages로 배포하면 휴대폰에서 앱처럼 홈 화면에 추가해 사용할 수 있습니다. 자세한 구현 계획은
`docs/UPGRADE_PLAN.md`, `docs/DEPTH_PLAN.md`, 밸런스 검증 과정은 `docs/SIMULATION_REPORT.md`를 참고하세요.

## 주요 시스템

- **주인공**: 윤영운으로 고정. 대화·서사에서 이름으로 등장합니다.
- **기숙사 선택**: 그리핀도르 / 슬리데린 / 레번클로 / 후플푸프 중 선택, 각기 다른 스탯 보너스
- **능력 판정**: 지식·용기·매력·민첩·행운 5스탯 기반 판정. 선택지에 성공률이 사전 표시되며 대성공/성공/실패/대실패 4단계로 갈립니다. 실패해도 보상을 주지 않고, 대실패에는 실질적인 페널티가 있습니다. 기억(아래 참고)이 있으면 판정에 보정치가 붙기도 합니다.
- **턴(시간대) 시스템**: 기력 대신 하루 3시간대(🌅 아침 · ☀️ 오후 · 🌙 밤)를 씁니다. 탐험·수업만 시간대를 소모하고 전투·대화·상점은 무료라, 중요한 순간에 자원이 떨어져 끊기는 일이 없습니다. 휴식은 무료지만 하루 전체를 소모하고, 대연회장 아침 식사나 페퍼업 포션(하루 한도 공유)으로 갈레온을 태워 시간대를 하나 더 살 수 있습니다.
- **마감**: 덤블도어의 의뢰마다 장(章)별 기한(D-day)이 있습니다. 넘겨도 즉시 실패는 아니지만, 두 번 이상 넘기면 보스가 강해지고 엔딩 등급이 한 단계 강등됩니다.
- **이동**: 장소 카드에 위험도·이동 비용과 함께 목적지 힌트(⭐ 메인 퀘스트 · ❗ 사이드 퀘스트 · 🏪 상점 등)를 미리 보여줍니다. 같은 구역 안 이동은 무료, 구역을 넘을 때만 시간대 1을 소모하며 도둑 지도가 있으면 그마저 무료입니다. 🗺️ 지도 버튼으로 구역별 미니맵(안개 효과 포함)을 볼 수 있습니다.
- **탐험**: 도서관·복도·금지된 숲·호그스미드 등에서 장소별 랜덤 이벤트 발생 (전투, 아이템, 판정 선택지, 사이드 퀘스트 체인). 이벤트에는 3단계 우선순위(메인 퀘스트 > 대형 이벤트 > 사이드 퀘스트 > 잡 이벤트)가 있어 핵심 이벤트가 잡다한 이벤트에 묻히지 않습니다.
- **퀘스트 로그**: 모험 탭 상단에 지금 진행 중인 메인 퀘스트·마감·사이드 퀘스트·연속 도전 상태를 상시 표시합니다.
- **기억(메모리) 시스템**: 특정 선택이 기억으로 남아, 나중에 회상 배너(💭)로 되살아나거나 전용 선택지·판정 보정을 엽니다. 메인 스토리 4챕터에도 각각 2~3개의 실제 선택지가 있으며, 선택은 캐릭터 탭의 "기억" 목록에 쌓이고 일부는 결말 문장에도 반영됩니다.
- **연속 도전형 퀘스트**: 연속 N회 성공해야 완료되고 실패하면 리셋되는 도전(예: 빗자루 균형 훈련, 패트로누스 수련). "두 번 성공했는데 세 번째에 실패"하는 긴장감을 줍니다.
- **체인 퀘스트 · 시련**: 보가트(두려움 선택) → 디멘터 조우(회상) → 패트로누스 수련 → 더 어려운 패트로누스 시련으로 이어지는 5단계 체인. 시련을 완수하면 게임 최초로 성물(artifact) 등급 장비와 디멘터 완전 무효 효과를 얻습니다.
- **대형 이벤트**: 핼러윈 트롤 소동, 퀴디치 시합, 겨울 무도회 등 원작의 굵직한 장면을 재현한 일회성 이벤트
- **전투**: 주문(공격/방어/치유/유틸리티)·아이템·방어·도주로 구성된 턴제 전투. 방어 계열 주문마다 방어력이 다릅니다.
- **주문 습득**: 레벨업 자동 습득 없음. 수업 수강(진도제)·주문서·대화 크리티컬(사사)·금서 해독·보스 드랍·체인 퀘스트 보상의 경로로만 습득. 사용할수록 숙련도가 올라 위력이 강해집니다.
- **아이템 파밍**: 6등급 희귀도(평범~성물) + 랜덤 접두/접미 옵션. 미확인 장비는 지식 판정으로 감정, 마법석으로 +10까지 강화(실패 시 등급 하락), 올리밴더에서 지팡이 뽑기 가능. 최상급 장비는 상점에서 팔지 않고 강력한 적의 전리품이나 시련 보상으로만 획득.
- **동료**: 헤르미온느·론·루나·네빌과의 호감도. 60에서 우정의 선물, 90에서 보스전 전용 1회성 지원 스킬 해금
- **업적·칭호·일일 과제**: 업적 달성 시 영구 스탯 보너스, 칭호 장착, 매일 갱신되는 일일 과제, 새 게임+(업적·도감 계승)
- **상점**: 허니듀크스(물약, 페퍼업 포션, 도둑 지도), 올리밴더(지팡이/방어구/주문서/뽑기) 이용
- **성향 시스템**: 선택과 어둠의 주문 사용 여부에 따라 성향이 변화하며 최종 엔딩에 영향
- **메인 스토리**: 실종 사건 조사 → 금지된 숲 → 비밀의 방 → 최종 결전으로 이어지는 4단계 이야기, 각 챕터마다 태도를 고르는 실제 선택지 포함
- **엔딩**: 빛의 마법사 / 균형 잡힌 자 / 어둠에 물든 자 / 함께한 자(동료 호감도 기반) / 쓰러진 자, 5종. 마감을 거듭 어기면 강등되고, 3장의 선택이 결말 문장에 반영됩니다.
- **문체**: 판정·효과 수치는 본문과 분리된 별도 칩(예: "지식 +2 · 경험치 +12")으로 표시되어 서사 문장에 숫자를 직접 적지 않습니다. 긴 본문은 문단 단위로 끊어 타이핑되어 호흡을 줍니다.
- **접근성**: 설정에서 타자 속도(느리게/보통/빠르게/즉시 표시) 조절, 연출 줄이기 토글(기본 켜짐 — 화면 흔들림·점멸 효과를 전역으로 억제) 지원. 화면 아무 곳이나 눌러 타자 애니메이션을 즉시 건너뛸 수 있습니다.
- **모바일 UI**: 하단 탭(모험/캐릭터/소지품/도감/기록), 타이프라이터 로그, 토스트, 바텀시트, 판정 연출+햅틱
- **저장/불러오기**: 브라우저 localStorage 기반, 버전 관리 및 자동 저장

```
  spells.js            주문, 과목, 숙련도 구간

  story.js             메인 스토리 챕터 (챕터별 분기 선택지 포함)
  endings.js           엔딩
  achievements.js      업적, 칭호, 일일 과제 템플릿
  companions.js        동료 데이터
  memories.js          기억 메타데이터, 패트로누스 형태 매핑

js/systems/             핵심 로직 모듈
  check.js             능력 판정 시스템 (기억 보정 지원)
  item.js              장비 인스턴스 생성·감정·강화
  loot.js              드랍 테이블, 지팡이 뽑기
  spell.js             주문 습득·숙련도
  achievement.js       업적·칭호·일일 과제·도감 완성도
  settings.js          타자 속도·연출 줄이기 등 기기 단위 설정

js/state.js            게임 상태 생성, 저장/불러오기 (버전 관리)
js/engine.js           게임 로직(턴/마감, 이동, 탐험, 전투, 상점, 스토리, 동료, 기억, 퀘스트 로그, 엔딩 진행)
js/ui.js               모바일 UI 렌더링 (탭, 토스트, 바텀시트, 타이프라이터, 미니맵, 퀘스트 로그, 설정 시트)
js/pwa.js              서비스 워커 등록
js/main.js             초기 진입점

scripts/simulate.js    헤드리스 밸런스 시뮬레이터 (개발 도구, 게임 번들에는 미포함)
```

## 부록 — 출산 일정표 (`birth-schedule/`)

이 저장소에는 게임과 별개로, 출산 준비부터 집에 돌아오기까지를 정리한 정적 페이지가 함께 들어 있습니다.

```
python3 -m http.server 8080
# 이후 브라우저에서 http://localhost:8080/birth-schedule/ 접속
```

- **타임테이블**: 준비기(D-30) → 입원·분만 → 병원 입원 → 산후조리원 → 집 복귀 → 이후 기한 일정
- **준비물 · 할일**: 출산가방, 서류, 조리원 짐, 집 신생아 세팅, 산모 회복 용품, 비상 대응, 출산 후 행정
- 자연분만(총 17일) / 제왕절개(총 18일) 시나리오 전환, 출산 예정일 입력 시 실제 날짜·요일 자동 계산,
  오늘 날짜 하이라이트, 체크 상태 저장(localStorage), 인쇄용 레이아웃 지원

게임 코드와는 완전히 분리되어 있으며 (`birth-schedule/` 안에서 자체 완결), 루트 서비스 워커는 이 경로를
캐시하지 않습니다.
