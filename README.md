# 호그와트: 그림자의 잔영

서울 2033, 모험과 이야기류의 한국형 텍스트 RPG 구조(스탯 관리·탐험·전투·상점·분기 스토리)를
해리포터 세계관 위에 얹은 브라우저 텍스트 게임입니다. 서버 없이 정적 파일만으로 동작하며, PWA로
홈 화면에 설치해 오프라인으로도 플레이할 수 있습니다. (개인적·비상업적 팬 프로젝트)

## 실행 방법

`index.html`을 브라우저로 열면 바로 플레이할 수 있습니다. (모바일 브라우저 권장 — 하단 탭 UI가 모바일 화면에 맞춰져 있습니다)

```
python3 -m http.server 8080
# 이후 브라우저에서 http://localhost:8080 접속
```

GitHub Pages로 배포하면 휴대폰에서 앱처럼 홈 화면에 추가해 사용할 수 있습니다. 자세한 구현 계획은
`docs/UPGRADE_PLAN.md`, 밸런스 검증 과정은 `docs/SIMULATION_REPORT.md`를 참고하세요.

## 주요 시스템

- **기숙사 선택**: 그리핀도르 / 슬리데린 / 레번클로 / 후플푸프 중 선택, 각기 다른 스탯 보너스
- **능력 판정**: 지식·용기·매력·민첩·행운 5스탯 기반 판정. 선택지에 성공률이 사전 표시되며 대성공/성공/실패/대실패 4단계로 갈립니다.
- **탐험**: 도서관·복도·금지된 숲·호그스미드 등에서 장소별 랜덤 이벤트 발생 (전투, 아이템, 판정 선택지, 사이드 퀘스트 체인)
- **전투**: 주문(공격/방어/치유/유틸리티)·아이템·방어·도주로 구성된 턴제 전투. 방어 계열 주문마다 방어력이 다릅니다.
- **주문 습득**: 레벨업 자동 습득 없음. 수업 수강(진도제)·주문서·대화 크리티컬(사사)·금서 해독·보스 드랍의 5가지 경로로만 습득. 사용할수록 숙련도가 올라 위력이 강해집니다.
- **아이템 파밍**: 6등급 희귀도(평범~성물) + 랜덤 접두/접미 옵션. 미확인 장비는 지식 판정으로 감정, 마법석으로 +10까지 강화(실패 시 등급 하락), 올리밴더에서 지팡이 뽑기 가능. 최상급 장비는 상점에서 팔지 않고 강력한 적의 전리품으로만 획득.
- **동료**: 헤르미온느·론·루나·네빌과의 호감도. 60에서 우정의 선물, 90에서 보스전 전용 1회성 지원 스킬 해금
- **업적·칭호·일일 과제**: 업적 달성 시 영구 스탯 보너스, 칭호 장착, 매일 갱신되는 일일 과제, 새 게임+(업적·도감 계승)
- **상점**: 허니듀크스(물약), 올리밴더(지팡이/방어구/주문서/뽑기) 이용
- **성향 시스템**: 선택과 어둠의 주문 사용 여부에 따라 성향이 변화하며 최종 엔딩에 영향
- **메인 스토리**: 실종 사건 조사 → 금지된 숲 → 비밀의 방 → 최종 결전으로 이어지는 4단계 이야기
- **엔딩**: 빛의 마법사 / 균형 잡힌 자 / 어둠에 물든 자 / 함께한 자(동료 호감도 기반) / 쓰러진 자, 5종
- **모바일 UI**: 하단 탭(모험/캐릭터/소지품/도감/기록), 타이프라이터 로그, 토스트, 바텀시트, 판정 연출+햅틱
- **저장/불러오기**: 브라우저 localStorage 기반, 버전 관리 및 자동 저장

## 파일 구조

```
index.html            화면 골격
manifest.json, sw.js  PWA 매니페스트 · 서비스 워커
icons/                PWA 아이콘
css/style.css         스타일

js/data/               정적 게임 데이터
  houses.js            기숙사, 5스탯 메타
  rarity.js            희귀도, 접사, 장비 템플릿, 지팡이 코어, 소모품
  spells.js            주문, 과목, 숙련도 구간
  enemies.js           적 데이터
  locations.js         장소, 상점
  events.js            랜덤 탐험 이벤트 (판정 스키마, 사이드 퀘스트 포함)
  story.js             메인 스토리 챕터
  endings.js           엔딩
  achievements.js      업적, 칭호, 일일 과제 템플릿
  companions.js        동료 데이터

js/systems/             핵심 로직 모듈
  check.js             능력 판정 시스템
  item.js              장비 인스턴스 생성·감정·강화
  loot.js              드랍 테이블, 지팡이 뽑기
  spell.js             주문 습득·숙련도
  achievement.js       업적·칭호·일일 과제·도감 완성도

js/state.js            게임 상태 생성, 저장/불러오기 (버전 관리)
js/engine.js           게임 로직(이동, 탐험, 전투, 상점, 스토리, 동료, 엔딩 진행)
js/ui.js               모바일 UI 렌더링 (탭, 토스트, 바텀시트, 타이프라이터)
js/pwa.js              서비스 워커 등록
js/main.js             초기 진입점

scripts/simulate.js    헤드리스 밸런스 시뮬레이터 (개발 도구, 게임 번들에는 미포함)
```
