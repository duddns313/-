# 호그와트: 그림자의 잔영

「모험가 이야기」류의 **텍스트 로그라이크**입니다. 진행도 게이지가 앞으로만 흐르고,
그 위로 랜덤 인카운터가 쏟아지며, 문턱마다 고정 스토리가 끼어듭니다.
한 판 30~50분. 죽거나 진행도 100%면 끝나고, 회차를 거듭해 **잊힌 이름을 되찾습니다.**

서버 없이 정적 파일만으로 동작하고, PWA로 홈 화면에 설치해 오프라인으로도 플레이할 수 있습니다.
(개인적·비상업적 팬 프로젝트)

## 실행

```
python3 -m http.server 8080
# http://localhost:8080
```

밸런스 검증용 헤드리스 시뮬레이터:

```
node scripts/simulate.js 200         # 붙들기 없이
node scripts/simulate.js 200 --hold  # 이름을 붙드는 플레이어
```

설계의 근거와 확정 수치는 전부 **`docs/ADVENTURE_PLAN.md`** 에 있습니다.
세계 규칙과 사건의 전모는 `docs/STORY_BIBLE.md`.

## 핵심 구조

### 진행도 하나가 축이다

"큰 스토리 라인"과 "랜덤 인카운트"는 별개 시스템이 아닙니다. 랜덤 인카운터가 게이지를
밀어올리고, 게이지가 문턱(10 · 28 · 46 · 68 · 88)을 넘으면 **고정 스토리 비트**가
강제로 끼어듭니다. 매 판 같은 뼈대를 지나되 사이를 채우는 살이 매번 다릅니다.

### 죽는 방법이 셋이다

| 자원 | 0이 되면 |
|---|---|
| **체력** | 사망 엔딩 (배경별로 문장이 다름) |
| **명부** — 붙들고 있는 이름 | 「혼자 남은 자」 |
| **진행도** 100% | 최종 대면 → 배경별 엔딩 |

진행도가 오를수록 명부의 이름이 지워집니다(**침식**). 흐려진 이름은 **붙들기**로
되돌립니다 — 소리 내어 부르고 체력 4를 냅니다. 반대로 이름을 통째로 잃으면
**최대 체력이 12 줄어듭니다.** 나도 그만큼 얇아지는 것입니다.

그래서 어느 쪽도 공짜가 아닙니다. 실측으로 두 전략의 사망률은 같고,
**남은 이름 수만 갈립니다**(붙들면 2.6명, 안 붙들면 1.4명).

### 「기록」 — 회차를 넘는 유일한 것

세계 규칙 4는 "읽어도 붙들지 못한다"입니다. 그래서 영운은 매 회차 잊은 채 시작하고,
**플레이어만 기억합니다.** 회차를 넘어 남는 건 손으로 적은 것뿐입니다 —
이름, 이름 조각, 엔딩 도감, 상위 특성, 주문 지식.

**스탯·장비·레벨은 절대 계승되지 않습니다.** 성장한 것은 캐릭터가 아니라 플레이어입니다.

라비니아 애슈의 이름은 조각 6개로 쪼개져 있고, 회차에 걸쳐 모아야 합니다.
여섯이 다 모여야 최종 대면에서 **「이름을 부른다」**가 열립니다. (진엔딩)

### 전투 — d20 + 주문 사슬

유니콘 오버로드 방식입니다. 전투 중에 조작하지 않고, **전투 전에 프로그래밍**합니다.

```
주문 사슬                              AP 3/3

1 ▸ 프로테고          [굴림 7 이하]
2 ▸ 익스펠리아무스     [첫 수]
3 ▸ 에피스키          [내 체력 50% 미만]
4 ▸ 스투페파이        [항상]
```

d20을 한 번 굴리고, 사슬이 위에서부터 자동 실행됩니다. **발동한 주문이 전장 상태를
갱신하고, 갱신된 상태가 다음 슬롯의 조건 판정에 반영됩니다.** 그래서 순서 배치가 실력입니다.
슬롯은 많고(최대 7) AP는 적어서(최대 4) "무엇을 넣느냐"보다 "언제 나가게 하느냐"가 중요합니다.
20이면 무조건 승리, 1이면 사슬 전체 무효.

### 그 밖에

- **배경 4종** — 편입생 / 유족 / 기록관 견습 / 잔영에 닿은 아이. 고정 비트의 진입 경로와 전용 엔딩이 갈립니다
- **판정** — `50 + (스탯 − DC) × 5 + 행운보정`. 성공률을 버튼에 미리 표시하고, 대성공/성공/실패/대실패 4단계
- **성장** — 진행도(시간)와 경험치(실력)를 분리해, 같은 진행도에서도 레벨이 갈립니다. 레벨업마다 포인트 2점 직접 분배
- **마법 습득** — 자동 습득 없음. 수업·주문서·사사·금서로만. 수업에서 실패해도 숙련도는 오릅니다
- **어빌리티** — 장비에 붙는 전투 패시브 8종. 「이름값」(붙든 이름당 위력 +2), 「잉크의 가호」(승리 시 침식 지연)처럼 침식과 전투를 잇는 것들이 있습니다
- **아이템** — 6등급 희귀도 + 접두/접미, 미확인 장비 감정, +10 강화
- **엔딩 15종** — 도감에 모입니다. 5·10·14종마다 다음 판 시작 보너스

## 파일 구조

```
index.html            화면 골격
manifest.json, sw.js  PWA (sw.js의 ASSETS는 index.html의 script 목록과 일치해야 함)
css/style.css         스타일

js/data/
  backgrounds.js       배경 4종
  traits.js            특성 8종 (기본 4 + 상위 4)
  fragments.js         라비니아의 이름 조각 6개
  beats.js             고정 스토리 비트 5개 × 배경별 변주
  encounters/          랜덤 인카운터 풀
    common.js            일상 — 수업·복도·식사·기숙사
    search.js            조사 — 단서·기록·인물
    combat.js            전투 조우
    eerie.js             괴이 — 잔영의 징후
    special.js           경보·특성 승급 (추첨 대상 아님)
  houses.js spells.js enemies.js people.js rarity.js endings.js achievements.js

js/systems/
  progress.js          진행도 · 스케줄러 · 가중 추첨 ⭐
  ledger.js            「기록」 영구 저장 (회차 계승) ⭐
  loadout.js           주문 사슬 편성 + 조건 평가 ⭐
  duel.js              d20 전투 해결 ⭐
  register.js          명부 · 침식 · 붙들기
  check.js item.js loot.js spell.js achievement.js settings.js

js/state.js            판(run) 상태, 저장/불러오기
js/engine.js           효과 적용 · 성장 · 소지품 · 엔딩
js/ui.js               모바일 UI (4탭, 타이프라이터, 바텀시트)
js/main.js             진입점

scripts/simulate.js    헤드리스 밸런스 시뮬레이터 (게임 번들 미포함)
```
