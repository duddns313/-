# 호그와트 7년

해리 포터와 같은 해(1991년)에 길 건너 소꿉친구 **이호현**과 함께 그리핀도르에 입학한 **윤영운**이 되어, 원작의 호그와트 7년을 사건 카드로 겪는
텍스트 어드벤처입니다. 서울 2033 · 모험가 이야기처럼 사건이 끊임없이 터지고, 소지품·주문·관계·
**예전의 선택(기억)**과 체력·정신력·평판이라는 대가에 따라 선택지와 결과가 달라집니다. (개인적·비상업적 팬 프로젝트)

> 현재 **1학년(마법사의 돌) 시험판**입니다. 기획 전체는 [`docs/GAME_PLAN.md`](docs/GAME_PLAN.md)를 보세요.

## 실행

`index.html`을 브라우저로 열거나:

```
python3 -m http.server 8080   # → http://localhost:8080
```

GitHub Pages에 올리면 휴대폰 홈 화면에 앱처럼 설치해 오프라인으로도 할 수 있습니다.

## 1학년 시험판에 들어 있는 것

- **프롤로그 12장면** — 같은 날 마주 본 두 가게(윤씨네 식품점·서울 마트)에 날아온 두 장의 편지, 10년 만에 한 식탁에 앉은 두 엄마, 다이애건 앨리, 9와 3/4 승강장, 호그와트 특급(호현의 "선"), 분류 모자, 그리핀도르 탑의 첫날 밤
- **관계 연작** — 호현(신뢰가 쌓이면 자기 이야기를 꺼낸다), 헤르미온느(질문 공책), 론(체스·물려받은 것들·거울), 해리(계단 밑 벽장·빗속 연습·투명 망토). 호감도가 오를수록 다음 이야기가 열린다. 인물 설계는 [`docs/CHARACTERS.md`](docs/CHARACTERS.md)
- **정사 사건** — 첫 수업 주간, 스네이프의 마법약, 비행 수업(기억구슬), 핼러윈 트롤(화장실·교수에게 알리기 등 여러 길), 첫 퀴디치, 크리스마스(남기/집에 가기) · 소망의 거울, 150점, 금지된 숲 벌칙(평판이 낮거나 밤에 걸렸을 때), 기말시험, 마지막 밤(뚜껑 문), 퀴렐의 정체 맞추기(모은 단서에 따라 달라짐), 기숙사컵, 귀향
- **장소 사건 40여 개** — 12번의 턴마다 행선지 카드 3장 중 하나를 골라 그 장소의 사건을 만납니다. 피브스, 움직이는 계단과 4층 복도, 자정의 결투, 해그리드와 노버트, 대왕오징어, 주방의 집요정, 울보 머틀, 독수리 문고리 수수께끼, 빗자루 연습 등
- 한 회차에 만나는 사건은 전체의 절반 정도라, 다른 선택으로 다시 할 이유가 있습니다.

## 시스템 (v8 — 주사위 없는 「열쇠와 대가」)

| | |
|---|---|
| 판정 | **주사위·성공률·능력치 없음.** 고른 선택지의 결과가 그대로 일어난다 |
| ❤️ 체력 · 💭 정신력 | 한도 5, ❤️4 💭4로 시작. 몸 쓰는 선택은 ❤️, 무섭고 슬프고 맞서는 선택은 💭가 든다. **0이 되면 게임 오버(처음부터, 프롤로그는 건너뛸 수 있다).** 저절로 차오르지 않는다 — 휴게실에서 자기, 먹을 것, 집 소포, 친구 장면으로 채운다 |
| ⭐ 평판 | 문제아 · 눈총 · 보통 · 신뢰 · 모범. 높으면 좋은 사건(맥고나걸의 생강 과자, 퍼시의 공책…), 낮으면 귀찮은 사건(필치의 서랍, 스네이프의 추가 과제, 말포이의 소문…)과 밤에만 가는 곳 폐쇄. 거짓말·규칙 위반으로 **평판을 깎아 당장의 위기를 넘기거나 좋은 보상**을 얻을 수 있다 |
| 🪙 갈레온 | 집에서 오는 소포·장사·내기로 모아 **🦉 부엉이 주문서**에서 산다 (폭죽·풍선껌·용가죽 장갑·베조아르·스펠로테이프·개 비스킷·겨울 망토·간식·페퍼업 물약) |
| 선택지 | 최대 4개. 열쇠(물건·주문·기억·친구·평판)와 대가(❤️·💭·⭐·🪙)를 요구할 수 있고, 둘을 함께 요구하거나 열쇠로 회복할 수도 있다. 모자라면 회색으로 잠긴다. 표시: `🧤 용가죽 장갑 · ❤️-1`. 물건이 쓰여 사라지는지는 결과에서만 안다 |
| 대신하는 길 | 다른 선택지를 하나도 고를 수 없을 때만 나타나는, 같은 장면의 덜 좋은 결말 |
| 특별 보상 | 🪄 주문 · 💭 기억 · 🎒 물건만 미리 보여 준다. 관계·평판·나중에 이어지는 결과는 숨는다 |
| ⏪ 호현의 되감기 | 10월, 영운은 세상이 몇 분 전으로 돌아가는 걸 겪는다. **영운만 기억한다.** 결과를 본 뒤 1년에 세 번 되감을 수 있고, 쓸수록 호현이 아파한다(두통 → 코피 → 쓰러짐) |
| 쓰러지기 직전 | ❤️나 💭가 1이 되면 1년에 한 번씩 폼프리 부인이나 친구가 붙잡아 준다 |
| 위기 | 트롤, 퀴렐의 연구실(망각 마법 — 단서 하나를 잃을 수 있다), 노버트가 떠나는 밤, 금지된 숲, 마지막 밤(굳은 네빌 → 피브스 → 깨어나는 머리 셋 개 → 덤블도어) — 대가 2까지 |
| 어른들의 이야기 | 우드의 비밀 연습 · 회색 숙녀의 수수께끼 · 스프라우트의 온실 조수 · 쌍둥이의 동업자 · 플리트윅의 특별 수업 — 한 일과 관계로 열린다 |
| 수집 | 개구리 초콜릿 카드 16종, 기억(열쇠가 되는 순간들), 인물 관계 |
| 접근성 | 타자 속도 4단계, 연출 줄이기(기본 켜짐), 글자 크기 3단계, 양피지/밤 테마, 화면을 누르면 바로 전부 표시 |

## 파일 구조

```
index.html · css/style.css · manifest.json · sw.js
js/data/meta.js           자원·기숙사·장소·주문·소지품·인물·카드·기억·달력
js/data/year1/*.js         1학년 사건 (prologue · canon_autumn · canon_spring · places_castle · places_grounds · bonds · crisis · stories · system)
js/core/                   state(저장) · rules(조건·대가·효과) · game(턴·행선지·진행) — DOM 없음
js/ui/                     settings · ui(화면)
tools/validate.js          사건 데이터 검증 (참조 오류, 렌더 오류, 막히는 사건, 예전 필드, 표기)
tools/simulate.js          자동 플레이 N회 × 3성향(조심·무작위·욕심) — 게임 오버율, 자원 흐름, 사건 노출률
```

사건을 추가하거나 고친 뒤에는 `node tools/validate.js && node tools/simulate.js`로 확인하세요.
