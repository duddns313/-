# 호그와트 7년 — 마지막 접기

**나는 이미 한 번 7년을 살았다.** 소꿉친구 이호현과 나는 해리 포터의 길을 — 원작의 그 수많은 "우연"들을 — 뒤에서 하나씩 만들어 냈다.
그리고 1998년 5월, 마지막에 하나가 모자랐다. **네빌이었다.** 호현은 남은 모든 힘으로 세상을 1991년 여름까지 접었고, 그 대가로 기억을 잃었다.
이번이 마지막 기회다. 1인칭 텍스트 어드벤처입니다. (개인적·비상업적 팬 프로젝트)

> 현재 **1학년(마법사의 돌) 시험판 · v9 1단계**입니다. 이야기 설계는 [`docs/STORY_V9.md`](docs/STORY_V9.md), 기획 전체는 [`docs/GAME_PLAN.md`](docs/GAME_PLAN.md)를 보세요.

## 1학년 시험판에 들어 있는 것

- **콜드 오픈** — 1998년 5월, 호그와트 전투의 마지막 밤. "젠장, 네빌이었어." 그리고 호현의 마지막 접기
- **프롤로그 10장면** — 다이애건 앨리에서 1991년의 헤르미온느, 지팡이, 9와 3/4 승강장, 호그와트 특급(트레버 · 개구리 초콜릿 · 말포이의 손), 분류 모자("두 번 쓴 머리로구나"), 첫날 밤
- **📓 일기장 — 운명의 매듭 20개** — 원작의 우연 하나하나가 매듭이다. 🪢 묶음 · 〰️ 느슨함 · ✂️ 끊김. 기한까지 손쓰지 않으면 끊긴다. 무거운 매듭은 학년말 결말을, 🌱 네빌의 매듭은 네빌의 용기를 가른다. 지금은 9~11월 초의 8개(승강장 · 트레버 · 덤블도어 카드 · 말포이의 악수 · 기억구슬 · 자정의 결투 · 트롤 · 스네이프의 다리)가 이야기로 들어 있다
- **관계 연작** — 기억을 잃은 호현(가끔의 기시감), 헤르미온느, 론, 해리, 네빌
- **정사 사건** — 첫 수업 주간, 마법약, 첫 퀴디치, 크리스마스와 소망의 거울, 150점, 금지된 숲, 기말시험, 마지막 밤, 기숙사컵, 귀향
- **장소 사건 40여 개** — 12번의 턴마다 행선지 카드 3장 중 하나를 골라 그 장소의 사건을 만납니다
- 모든 지문은 1인칭("나")입니다. 나의 성격은 설명하지 않습니다 — 플레이어가 나입니다.

## 시스템 (v8 「열쇠와 대가」 + v9 「매듭」)

| | |
|---|---|
| 판정 | **주사위·성공률·능력치 없음.** 고른 선택지의 결과가 그대로 일어난다 |
| ❤️ 체력 · 💭 정신력 | 한도 5, ❤️4 💭4로 시작. 몸 쓰는 선택은 ❤️, 무섭고 슬프고 맞서는 선택은 💭가 든다. **0이 되면 게임 오버(처음부터, 프롤로그는 건너뛸 수 있다).** 저절로 차오르지 않는다 — 휴게실에서 자기, 먹을 것, 소포, 친구 장면으로 채운다 |
| ⭐ 평판 | 문제아 · 눈총 · 보통 · 신뢰 · 모범. 높으면 좋은 사건(맥고나걸의 생강 과자, 퍼시의 공책…), 낮으면 귀찮은 사건(필치의 서랍, 스네이프의 추가 과제, 말포이의 소문…)과 밤에만 가는 곳 폐쇄. 거짓말·규칙 위반으로 **평판을 깎아 당장의 위기를 넘기거나 좋은 보상**을 얻을 수 있다 |
| 🪙 갈레온 | 다이애건 앨리에서 남은 돈·소포·장사·내기로 모아 **🦉 부엉이 주문서**에서 산다 (폭죽·풍선껌·용가죽 장갑·베조아르·스펠로테이프·개 비스킷·겨울 망토·간식·페퍼업 물약) |
| 선택지 | 최대 4개. 열쇠(물건·주문·기억·친구·평판)와 대가(❤️·💭·⭐·🪙)를 요구할 수 있고, 둘을 함께 요구하거나 열쇠로 회복할 수도 있다. 모자라면 회색으로 잠긴다. 표시: `🧤 용가죽 장갑 · ❤️-1`. 물건이 쓰여 사라지는지는 결과에서만 안다 |
| 대신하는 길 | 다른 선택지를 하나도 고를 수 없을 때만 나타나는, 같은 장면의 덜 좋은 결말 |
| 피할 수 없는 대가 | 트롤, 1월의 감기, 퀴렐의 망각 마법, 금지된 숲, 깨어나는 개 — 준비(물건·주문·체력)가 없으면 억지로라도 치러야 하고, 그게 마지막 한 칸이면 쓰러진다 |
| 🪄 주문 9개 | 루모스 · 녹스 · 레파로(오쿨루스 레파로) · 윙가르디움 레비오사 · 알로호모라 · 페트리피쿠스 토탈루스 · 푸른 불꽃 · 로코모토르 모르티스(다리 묶기) · 피니테 인칸타템. 수업·헤르미온느의 목요일 모임·복습 시간·도서관·어른들의 이야기에서 배우고, 30곳 넘는 장면에서 열쇠가 된다 |
| 특별 보상 | 🪄 주문 · 💭 기억 · 🎒 물건만 미리 보여 준다. 관계·평판·나중에 이어지는 결과는 숨는다 |
| ⏪ 호현의 되감기 | 호현에게 남은 능력의 잔향. 10월, 세상이 몇 분 전으로 돌아간다. **나만 기억한다.** 결과를 본 뒤 1년에 세 번 되감을 수 있고, 쓸수록 호현이 아파한다(두통 → 코피 → 쓰러짐) |
| 쓰러지기 직전 | ❤️나 💭가 1이 되면 1년에 한 번씩 폼프리 부인이나 친구가 붙잡아 준다 |
| 위기 | 트롤, 퀴렐의 연구실(망각 마법 — 단서 하나를 잃을 수 있다), 노버트가 떠나는 밤, 금지된 숲, 마지막 밤(굳은 네빌 → 피브스 → 깨어나는 머리 셋 개 → 덤블도어) — 대가 2까지 |
| 어른들의 이야기 | 우드의 비밀 연습 · 회색 숙녀의 수수께끼 · 스프라우트의 온실 조수 · 쌍둥이의 동업자 · 플리트윅의 특별 수업 — 한 일과 관계로 열린다 |
| 수집 | 개구리 초콜릿 카드 16종, 기억(열쇠가 되는 순간들), 인물 관계 |
| 접근성 | 타자 속도 4단계, 연출 줄이기(기본 켜짐), 글자 크기 3단계, 양피지/밤 테마, 화면을 누르면 바로 전부 표시 |

## 파일 구조

```
index.html · css/style.css · manifest.json · sw.js
js/data/meta.js           자원·기숙사·장소·주문·소지품·인물·카드·기억·달력
js/data/year1/*.js         1학년 매듭(knots)과 사건 (prologue · autumn_knots · canon_autumn · canon_spring · places_castle · places_grounds · bonds · crisis · stories · system)
js/core/                   state(저장) · rules(조건·대가·효과) · game(턴·행선지·진행) — DOM 없음
js/ui/                     settings · ui(화면)
tools/validate.js          사건 데이터 검증 (참조 오류, 렌더 오류, 막히는 사건, 예전 필드, 표기)
tools/simulate.js          자동 플레이 N회 × 3성향(조심·무작위·욕심) — 게임 오버율, 자원 흐름, 사건 노출률
```

사건을 추가하거나 고친 뒤에는 `node tools/validate.js && node tools/simulate.js`로 확인하세요.
