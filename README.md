# 호그와트: 그림자의 잔영

서울 2033, 모험과 이야기류의 한국형 텍스트 RPG 구조(스탯 관리·탐험·전투·상점·분기 스토리)를
해리포터 세계관 위에 얹은 브라우저 텍스트 게임입니다. 서버 없이 정적 파일만으로 동작합니다.
(개인적·비상업적 팬 프로젝트)

## 실행 방법

`index.html`을 브라우저로 열면 바로 플레이할 수 있습니다.

```
python3 -m http.server 8080
# 이후 브라우저에서 http://localhost:8080 접속
```

## 주요 시스템

- **기숙사 선택**: 그리핀도르 / 슬리데린 / 레번클로 / 후플푸프 중 선택, 각기 다른 스탯 보너스
- **탐험**: 도서관·복도·금지된 숲·호그스미드 등에서 장소별 랜덤 이벤트 발생 (전투, 아이템, 선택지)
- **전투**: 주문(공격/방어/유틸리티)·아이템·방어·도주로 구성된 턴제 전투
- **성장**: 레벨업 시 스탯 상승 및 레벨에 따른 신규 주문 습득
- **상점**: 허니듀크스(물약), 올리밴더(지팡이/방어구) 이용
- **성향 시스템**: 선택과 어둠의 주문 사용 여부에 따라 성향이 변화하며 최종 엔딩에 영향
- **메인 스토리**: 실종 사건 조사 → 금지된 숲 → 비밀의 방 → 최종 결전으로 이어지는 4단계 이야기
- **엔딩**: 성향에 따라 빛의 마법사 / 균형 잡힌 자 / 어둠에 물든 자 엔딩 분기
- **저장/불러오기**: 브라우저 localStorage 기반 저장

## 파일 구조

```
index.html       화면 골격
css/style.css    스타일
js/data.js       기숙사·주문·아이템·적·장소·이벤트·스토리·엔딩 데이터
js/state.js      게임 상태 생성 및 저장/불러오기
js/engine.js     게임 로직(이동, 탐험, 전투, 스토리 진행)
js/ui.js         화면 렌더링
js/main.js       초기 진입점
```
