# v8 변환 지침 — 주사위 없는 「열쇠와 대가」 구조

이 문서는 `js/data/year1/*.js`의 사건을 v8 규칙으로 옮겨 쓰는 사람을 위한 것이다.
엔진(`js/core/rules.js`, `js/core/game.js`)과 검증기(`node tools/validate.js <파일이름>`)는 이미 v8이다.

## 1. 규칙 요약

- 능력치(용기·지혜·성실·기지·마법), 성공률, 주사위, 경험치, 레벨, 속마음은 **없다**.
- 자원: `hp`(❤️ 체력, 한도 5) · `mind`(💭 정신력, 한도 5) · `rep`(⭐ 평판 1~5: 문제아·눈총·보통·신뢰·모범) · `galleon`(🪙).
- ❤️ 또는 💭가 0이 되면 **게임 오버(처음부터)**. 시작은 ❤️4 💭4 ⭐3.
- 체력·정신력은 저절로 차오르지 않는다. 휴게실 쉬기·먹을 것·집 소포·친구 장면이 채운다.
- 고른 선택지의 결과는 **그대로 일어난다**. 실패 판정이 없다.

## 2. 선택지 스키마

```js
{
  label: '용가죽 장갑을 끼고 알을 들어 본다',
  needs: { item: 'gloves' },          // 열쇠 (없으면 회색으로 잠김). item·spell·memory·rel·repMin·card
  cost: { hp: 1 },                     // 대가 (모자라면 잠김). hp·mind·rep·galleon. 보통 1, 위기에서만 2
  consume: true,                       // needs.item을 쓰고 나면 사라진다 (플레이어에게는 미리 안 보임)
  fallback: true,                      // 다른 선택지를 하나도 고를 수 없을 때만 나타난다 (대가 없음)
  lockHint: '불에 달군 무언가를 만질 수 있다면…',   // 잠겼을 때 보이는 힌트 (선택)
  outcome: { text: `…`, fx: { … }, next: 'id' },   // 결과는 하나뿐
}
```

- `needs`와 `cost`를 **함께** 요구해도 된다 (예: `🧤 장갑 · ❤️-1`).
- 열쇠를 써서 **자원을 회복**해도 된다 (예: `needs:{item:'yakgwa'}, consume:true` → `fx:{mind:1}`).
- 선택지에 보이는 것: 열쇠 이름, 대가(❤️-1), 회복(❤️+1), 특별 보상(🪄 주문 · 💭 기억 · 🎒 물건). 그 밖의 결과(관계·평판 상승·flag)는 숨는다.
- **선택지 결과 `fx`에서 hp·mind를 깎지 않는다.** 깎는 건 반드시 `cost`로 미리 보여 준다. (사건 자체의 `ev.fx`나 특별 사건은 예외)
- 평판을 깎는 것도 원칙적으로 `cost: { rep: 1 }`로 보여 준다. 평판 깎기 = **당장의 위기를 벗어나거나 좋은 보상을 얻는 대가**.
- 평판 상승(`fx.rep: 1`)은 숨은 보상이다. 모범적인 행동에 아껴서 준다 (사건 8~10개에 1번꼴).

## 3. 사건 하나의 모양 (최대 4개)

| 종류 | 설명 |
|---|---|
| 공짜 선택지 | 열쇠도 대가도 없다. 관계·이야기 방향만 바뀐다 |
| 대가 선택지 | ❤️/💭/⭐/🪙 중 하나 이상. 더 좋은 결과 · 특별 보상 |
| 열쇠 선택지 | 물건·주문·기억·관계·평판이 있어야 열린다. 대가를 함께 걸어도 된다 |
| fallback | 위가 **모두** 막혔을 때만 보인다. 같은 장면에서 덜 좋은 결말. 대가 없음 |

- **사건마다 "항상 고를 수 있는 길"이 하나는 있어야 한다**: 공짜 선택지 하나, 또는 fallback. (검증기가 확인한다)
- 공짜 선택지가 있으면 fallback은 영영 안 보이니 붙이지 않는다.
- 다른 기숙사·다른 길로 빠지는 선택지는 만들지 않는다. 같은 장면 안에서 고른다.

## 4. 균형 (1년 ≈ 고르는 사건 35개)

- 사건의 약 **45%는 공짜만** (대화, 관계, 성격이 드러나는 선택).
- 약 **40%는 대가가 있는 사건** (대가 선택지 1~2개 + 공짜 또는 fallback).
- 약 **15%는 채우는 사건** (쉬기, 먹기, 집, 친구와 웃기). 회복은 보통 +1, 드물게 +2.
- 대가는 거의 항상 **1**. 위기(트롤, 퀴렐, 마지막 밤, 금지된 숲)에서만 2.
- ❤️ 대가: 몸을 쓰는 일, 위험, 밤샘, 부상을 감수. 💭 대가: 무서운 것과 맞서기, 갈등, 슬픔을 감당하기, 자존심 굽히기. ⭐ 대가: 거짓말, 규칙 위반, 밤 외출, 교수에게 대들기. 🪙: 돈을 쓰는 일.
- 평범한 일(수업 듣기, 공부, 대화)은 **공짜**다. 모든 걸 대가로 만들면 금방 쓰러진다.

## 5. 예전 데이터를 옮기는 법

| 예전 | v8 |
|---|---|
| `stat`, `dc`, `outcomes: {success, fail…}` | 행동의 성격으로 판단: 공짜 / `cost` 하나. `outcome`은 예전 **success** 글을 쓴다. 예전 **fail** 글은 쓸 만하면 fallback이나 다른 선택지의 결말로 고쳐 쓰고, 아니면 버린다 |
| `bonus: [...]` | 지운다. 이야기가 좋은 것만 별도의 열쇠 선택지로 만든다 (최대 4개 안에서) |
| `voice`, `sneak` | 지운다 |
| fx `heart: +n` | 진짜 쉬는 장면이면 `mind: 1`(또는 `hp: 1`), 아니면 지운다 |
| fx `heart: -n`, `hp: -n` | 지운다. 그 손실이 선택의 본질이면 `cost`로 옮긴다 |
| fx `notice: +n` | 일부러 규칙을 어기는 선택이면 `cost: { rep: 1 }`, 아니면 지운다 |
| fx `notice: -n` | 지운다 (또는 아주 모범적이면 `rep: 1`) |
| fx `courage/wisdom/…: n`, `xp`, `insight`, `curfew` | 지운다 |
| fx `points` | 그대로 둬도 된다 (이야기 속에만 쓰인다) |
| needs `resMin: { notice }`, `stat` | 지운다. 필요하면 `repMax: 2`나 flag로 |
| `MEMORY_TO_FLAG`에 있는 기억 | `memory: 'x'` → `flag: 'x'`, 텍스트의 `S_HAS(s,'x')` → `s.flags.x`, needs의 `memory:'x'` → `flag:'x'` |
| `dragon_book`, `invite_card` 아이템 | 없어졌다. 지운다 |
| 판정 결과를 설명하는 말("성공했다/실패했다") | 자연스럽게 고친다 |

- 텍스트 안의 "기운", "주목도", "능력치", "%" 같은 예전 시스템 말은 쓰지 않는다.
- 물건: 소모품(`dungbomb fireworks gum biscuits spellotape bezoar frog pasty beans yakgwa gimbap rockcake pepperup cloak_note`)을 열쇠로 쓰면 대개 `consume: true`. 오래 쓰는 물건(`gloves wintercloak hogwarts_history chess_knight sweater hohyeon_cap`)은 보통 남긴다. 가끔 예외가 있어도 좋다 (플레이어는 모른다).
- 기억은 `MEMORIES`에 있는 것만 준다. 새 기억을 만들지 않는다. 작은 일은 flag로.
- 아이템과 기억을 남발하지 않는다. 열쇠는 "있으면 좋은 길"이지 "없으면 막히는 길"이 아니다 — 열쇠 선택지 옆에는 언제나 다른 길이 있다.

## 6. 문체

- 원래 문장(롤링 풍 한국어 산문)은 최대한 살린다. 새로 쓰는 문장도 같은 결로.
- 선택지 라벨은 행동만 쓴다. 대가를 말투로 암시하지 않는다(예: "지친 몸을 이끌고" 같은 표현을 대가 설명용으로 붙이지 않는다). 대가는 UI가 보여 준다.
- 영운은 진취적이지만 걱정이 많고, 이타적이지만 고집이 있고, 당차 보여도 속으로 눈물이 많고, 의문은 끝까지 판다. 호현에게 기대는 아이가 아니다.
- 호현은 사회적이지만 남을 쉽게 안 믿고, 잘 들어 주지만 자기 이야기는 안 하고, 갈등을 피하지만 자신을 함부로 대하는 건 못 참는다.

## 7. 예시

예전:
```js
{ label: '"해그리드, 그거 용 알이죠?" 정직하게 묻는다', stat: 'courage', dc: 2,
  outcomes: {
    success: { text: `…`, fx: { courage: 1, flag: 'hag_egg', mark: 'hag_egg', rel: { hagrid: 10 } } },
    fail: { text: `…`, fx: { flag: 'hag_egg', mark: 'hag_egg' } },
  } },
```
v8 (평범한 대화 → 공짜):
```js
{ label: '"해그리드, 그거 용 알이죠?" 정직하게 묻는다',
  outcome: { text: `…(success 글)…`, fx: { flag: 'hag_egg', mark: 'hag_egg', rel: { hagrid: 10 } } } },
```

예전 (위험한 행동):
```js
{ label: '들고 있던 책으로 블러저를 쳐 낸다', stat: 'courage', dc: 5, outcomes: { success: {…}, fail: {…, fx: { hp: -10 } } } },
```
v8:
```js
{ label: '들고 있던 책으로 블러저를 쳐 낸다', cost: { hp: 1 },
  outcome: { text: `…(success 글)…`, fx: { rel: { harry: 8 } } } },
```

열쇠로 회복:
```js
{ label: '엄마가 보낸 약과를 반 나눠 준다', needs: { item: 'yakgwa' }, consume: true,
  outcome: { text: `…`, fx: { mind: 1, rel: { ron: 8 } } } },
```

fallback (위 선택지들이 모두 대가·열쇠일 때):
```js
{ label: '그냥 반장을 따라간다', fallback: true,
  outcome: { text: `…(예전 fail 글을 다듬어서)…`, fx: { flag: 'missed_troll' } } },
```
