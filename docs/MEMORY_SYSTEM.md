# 기억 시스템 — 플레이어가 직접 기억하는 게임

> 요청: *"기억한다는 것에 게임적 요소가 있었으면 좋겠음. 유저가 참여할 수 있도록"*

지금까지의 `memory`는 **보이지 않는 플래그**였습니다. 모아도 플레이어는 모으는 줄 몰랐고,
판정 보정 몇 %만 조용히 바뀌었습니다. 이걸 **플레이어가 손으로 하는 일**로 바꿉니다.

---

## 0. 설계 원칙

> **잊는 것은 게임이 하고, 붙드는 것은 플레이어가 한다.**

1. 잊힘은 **실제로 화면에서 글자가 지워지는 것**으로 보여준다. 서술로 설명하지 않는다
2. 붙드는 데는 **비용**이 든다. 하루를 쓰거나, 판정을 하거나
3. 전부 붙들 수는 없다. **무엇을 포기할지가 결정**이 된다
4. 마지막에 붙든 것이 **그대로 무기**가 된다
5. ⚠ 접근성: 지워짐은 **점멸·흔들림 없이** 색 변화와 문자 치환으로만 표현

---

## 1. 명부 (The Register) ⭐ — 핵심 화면

새 탭 **📖 명부**. 지금까지 만난 모든 사람이 한 페이지에 쌓입니다.

```
┌ 잊힌 이들의 명부 ──────────────────┐
│                                    │
│  ✓ 이디스 파넬        레번클로 6학년 │
│  ✓ 알버스 포터        슬리데린 6학년 │
│  ✓ 로즈 그레인저-위즐리 그리핀도르     │
│  ⚠ 스콜피우스 말▓▓▓   슬리데린 6학년 │  ← 침식 1단계
│  ⚠ 토비아스 그▓▓▓     ▓▓▓▓▓▓       │  ← 침식 2단계
│  ✗ ▓▓▓▓▓▓▓▓         ▓▓▓▓▓▓       │  ← 침식 3단계 (잃음)
│                                    │
│  ─── 전사자 명부 (기념비) ───        │
│  ✓ 리머스 루핀                      │
│  ✓ 님파도라 통스                    │
│  ✓ 프레드 위즐리                    │
│  ✗ ▓▓▓▓▓ ▓▓▓         ← 세 번째 줄  │
│                                    │
│  붙들고 있는 이름  14 / 21          │
└────────────────────────────────────┘
```

- 인물을 만나면 자동 등재
- **기념비 명부**는 별도 구획. 여기가 지워지는 게 이야기의 시계
- 하단에 `붙들고 있는 이름 N개` — **이 숫자가 4막의 탄약**

## 2. 침식 (Erosion) — 게임이 실제로 정보를 지운다 ⭐

하루가 지날 때마다 잔영이 명부에서 하나를 갉아먹습니다.

| 단계 | 명부 표시 | 게임 전체에 미치는 영향 |
|:-:|---|---|
| **0 · 온전** | `이디스 파넬` | 정상 |
| **1 · 흐려짐** | `이디스 파▓` | 대사에서 성이 `▓`로 치환된다 |
| **2 · 지워짐** | `이디스 ▓▓` | 이름이 전부 치환. **동료 호감도 효과 정지** |
| **3 · 잃음** | `▓▓▓ ▓▓` | **명부에서 사라진다.** 관련 장면·선택지 소멸 |

### 실제로 어떻게 보이는가

침식 2단계 인물이 대사에 나오면 **본문의 글자가 진짜로 바뀝니다.**

> "▓▓▓가 아까부터 안 보이는데." 로즈가 말했다. "…누구라고 했지? 방금 내가 누구 얘기했지?"

플레이어는 이 사람이 누군지 **화면상으로 알 수 없게 됩니다.** 명부를 열어봐도 `▓▓▓`입니다.
설명이 아니라 **경험**입니다.

### 우선순위
1. 메인 플롯이 지정한 대상 (2막의 잊히는 동료 등)이 있으면 그것부터
2. 없으면 **최근에 상호작용하지 않은 인물**부터
3. 기념비 명부는 별도로 **3일에 한 번** 한 칸씩

> 💡 이 규칙 때문에 **동료를 방치하면 실제로 잃습니다.** 호감도 시스템이 살아납니다.

## 3. 붙들기 (Hold) — 플레이어의 행동 ⭐

명부에서 흐려진 이름을 눌러 **[붙든다]**를 선택합니다.

| 침식 단계 | 판정 | 비용 |
|:-:|---|---|
| 1 | 지식 DC 6 | 무료 (하루 1회) |
| 2 | 지식 DC 9 또는 매력 DC 8 | **1일** |
| 3 | 불가 — 다른 수단 필요 (§4) | — |

- 성공 → 침식 0으로 복구
- 실패 → 그대로. 재도전 가능하지만 하루가 또 간다
- **판정 스탯 선택 가능**: 지식(기록을 대조한다) / 매력(그 사람 이야기를 남에게 물어본다) /
  용기(잊힘에 정면으로 저항한다 — DC 높지만 체력 소모)

> **핵심 결정**: 하루는 유한하고 마감은 다가옵니다. **누구를 붙들고 누구를 놓을 것인가.**
> 이것이 이 게임의 중심 선택이 됩니다.

---

## 4. 되찾기 (Recover) — 3단계에서 살리는 법

완전히 잃은 이름은 판정으로 안 됩니다. **물증**이 필요합니다.

| 수단 | 획득처 | 효과 |
|---|---|---|
| **이디스의 수첩** | 1막 | 잃은 이름 1개를 읽어낼 수 있다. **하루 1회** |
| **손등 메모** | 기념비 장면에서 적었다면 | 기념비 1칸 복구 |
| **회색 여인의 증언** | 2막 | 엘리너 그레이 복구 (유령은 먹히지 않는다) |
| **도둑 지도** | 3막 | 빈 이름표 위치 → 그 인물 1명 복구 |
| **사진첩** | 허브 활동 | 구도가 어색한 사진에서 1명 추정 |

> **규칙 3·4**(잉크는 남지만 읽어도 못 붙든다)에 따라, 수첩을 읽어도 **영운만 붙들 수 있습니다.**
> 그래서 하루 1회 제한이 서사적으로 정당합니다.

## 5. 호명 (Calling) — 4막의 전투 ⭐

최종전에서 **물리 공격은 통하지 않습니다.** 유일한 행동은 **[이름을 부른다]**.

```
┌ 잔영 ─────────────────────── HP ████████░░ ┐
│                                             │
│  부를 수 있는 이름   14                       │
│                                             │
│  [ 이름을 부른다 ]                            │
│  [ 명부를 펼친다 ]                            │
│  [ 버틴다 ]                                  │
└─────────────────────────────────────────────┘
```

- **[이름을 부른다]** → 명부에서 하나 고른다. 부른 이름은 소진된다
  - 온전한 이름: 큰 피해
  - 침식 1: 절반
  - 동료(호감도 60↑): 그 동료가 함께 부른다 → 추가 피해 + 전용 대사
- 잔영은 매 턴 **명부에서 이름 하나를 더 먹습니다.** 오래 끌수록 탄약이 준다
- 이름이 떨어지면 패배

> 모아둔 것이 그대로 탄창이 됩니다. 게임 내내 "붙들까 말까" 고민한 것이 여기서 전부 정산됩니다.

## 6. 빈칸 지목 — 단 한 번의 진짜 참여 ⭐⭐

4막 마지막. 잔영을 몰아붙이면 게임이 멈추고 **기념비 세 번째 줄**을 보여줍니다.

```
전투 기념비 · 세 번째 줄

  … 콜린 크리비 ·  ▓▓▓▓▓▓  ·  라번더 브라운 …

  이 자리의 이름을 부르십시오.
```

플레이어가 **직접 이름을 고릅니다.** 명부에 등재된 이름 전체가 후보로 뜹니다.

- **정답: 라비니아 애슈**
- 3막에서 `knows_lavinia`를 얻었다면 명부에 있습니다
- 못 얻었다면 후보에 없고, 다른 이름을 불러야 합니다 → **차선의 결말**
- 틀려도 게임 오버는 아닙니다. 결말의 온도가 달라질 뿐

> **이 한 번만큼은 캐릭터가 아니라 플레이어가 기억해야 합니다.**
> 게임은 "외우세요"라고 말하지 않습니다. 붙든 사람은 알고, 놓은 사람은 모릅니다.
> 그게 이 이야기의 주제입니다.

## 7. 기억 조각 (Fragment) — 수집의 즐거움

무거운 것만 있으면 지칩니다. 가벼운 수집 축을 하나 둡니다.

- 따뜻한 장면·대화에서 **기억 조각**을 얻는다 (온실의 오후, 주방의 코코아, 부엉이장의 눈)
- 명부 아래 별도 칸에 카드처럼 쌓인다
- 게임 진행에는 영향 없음. **다만 4막에서 한 번, 조각으로도 이름을 부를 수 있다**
  - 사람 이름이 아니라 **순간**을 부르는 것. 잔영에게는 그것도 먹히지 않은 기억이다
  - 전용 연출 + 전용 업적

> 파밍·도감의 즐거움을 주제 안으로 끌어들입니다. 모으는 게 곧 저항입니다.

## 8. 데이터 규격

```js
/* state 추가 */
register: {
  'edith':   { name: '이디스 파넬', house: 'ravenclaw', erosion: 0, held: true },
  'lavinia': { name: '라비니아 애슈', memorial: true, erosion: 3, held: false },
},
fragments: ['greenhouse_afternoon', 'kitchen_cocoa'],
holdUsedDay: 0,        // 무료 붙들기 하루 1회 제한
notebookUsedDay: 0,    // 이디스 수첩 하루 1회 제한
```

```js
/* 인물 데이터 js/data/people.js (신규) */
const PEOPLE = {
  edith: {
    id: 'edith', name: '이디스 파넬', surname: '파넬', given: '이디스',
    house: 'ravenclaw', companion: true,
    erodible: true,            // 침식 대상인가
    recoverBy: ['notebook'],   // 3단계에서 되살릴 수단
  },
  lavinia: {
    id: 'lavinia', name: '라비니아 애슈',
    memorial: true, startErosion: 3,   // 게임 시작 시 이미 지워져 있다
    recoverBy: ['simon_confession'],
  },
};
```

### 텍스트 치환 함수 (엔진)

```js
/* 본문·대사·UI 전부 이 함수를 통과시킨다.
 * 침식 단계에 따라 이름을 ▓로 바꿔 출력한다. */
function veilName(personId) {
  const p = PEOPLE[personId];
  const e = (state.register[personId] || {}).erosion || 0;
  if (e === 0) return p.name;
  if (e === 1) return p.given + '▓'.repeat(p.surname.length);
  if (e >= 2)  return '▓'.repeat(p.name.length);
}
```

> 장면 본문에서는 `{{edith}}` 같은 자리표시자를 쓰고, 렌더 시 `veilName()`으로 치환합니다.
> **이래야 침식이 이미 쓴 문장에도 소급 적용됩니다.**

## 9. 접근성 (타협 불가)

- 침식 표현은 **색 변화 + 문자 치환**만. 점멸·흔들림·페이드아웃 애니메이션 **금지**
- `▓` 는 스크린리더에서 시끄러우므로 `aria-label="지워진 이름"` 부여
- 명부에서 잃은 항목이 **사라질 때 애니메이션 없이** 다음 렌더에서 그냥 없다
- `연출 줄이기` 켜짐 상태에서도 전부 동일하게 동작할 것
