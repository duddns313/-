# 문장 지침 — 번역투를 버리고, 친절하고 개연성 있게

플레이어 피드백 (v12):

> 너무 번역투라 마음에 안 든다. 스토리가 불친절하다. 시작부터 연기가 나는데 쇠맛이 왜 나는지, 호현이 왜 갑자기 이름을 잊는지 묻게 된다. 함축해서 묘사하면 안 된다. 더 이성적이고 섬세하게, 개연성 있게. 명사는 한국어판 소설의 명사를 쓴다.

## 1. 모든 묘사에는 이유가 있어야 한다

독자가 "왜?"라고 묻게 되는 감각 묘사, 행동, 대사는 같은 문단 안에서 이유를 밝힌다.

| 함축 (지양) | 친절하게 (지향) |
|---|---|
| 숨을 쉴 때마다 쇠 맛이 났다. | 숨을 쉴 때마다 목이 따가웠고, 입안에서는 피 맛이 났다. 조금 전 계단에서 넘어지면서 입술이 터진 탓이었다. |
| "…너, 이름이 뭐였지?" (설명 없음) | (앞에서) 시간 역행 마법은 되돌린 시간이 길수록, 마법을 건 사람이 그만큼의 기억을 잃는다고 했다. → "…너, 이름이 뭐였지?" |
| 그 눈이 나를 보았다. 무언가를 말하려 했다. | 네빌의 눈이 나를 향했다. 입은 굳어 움직이지 않았지만, 눈동자가 초상화 구멍 쪽을 몇 번이고 가리켰다. 누군가 저리로 나갔다는 뜻이었다. |

- 이야기의 규칙(시간 역행 마법, 갈림길, 첫 번째 삶)은 처음 나올 때 **한두 문장으로 분명하게** 설명한다.
- 장면이 바뀌면 **언제, 어디서, 누가, 무슨 일**인지를 첫 문단에 먼저 놓는다. 감정은 그 다음이다.
- "나"가 무언가를 할 때는 **왜 그래야 하는지** 생각의 순서를 보여 준다. ("해리가 날아야 수색꾼이 된다. 그러려면 네빌의 빗자루가 먼저 떠야 한다.")
- 원작의 사건을 언급할 때는 원작을 모르는 사람도 알 수 있게 한 줄을 덧붙인다. ("그리핀도르의 칼은 진정한 그리핀도르 학생이 간절히 필요로 할 때 분류 모자 안에서 나타난다.")

## 2. 번역투를 쓰지 않는다

| 번역투 | 자연스러운 우리말 |
|---|---|
| 그것은 ~한 것이었다 / ~하는 것이었다 | ~했다 |
| 그 애가, 그 애는 (남발) | 이름을 쓰거나 주어를 생략한다 |
| ~에 의해 ~되었다 | 능동문으로 |
| 한 박자 늦게, 숨을 들이켰다 (반복) | 상황에 맞는 구체적 동작 |
| 웃었다. 아무렇지 않은 얼굴로. (조각 문장 남발) | 웃었다. 늘 그렇듯 별일 아니라는 얼굴이었다. |
| ~하는 얼굴이었다 (반복) | 표정을 구체적으로, 또는 생략 |
| 그리고 ~했다. 그리고 ~했다. | 연결어미로 잇는다 (~하고, ~해서, ~자) |
| 나는 ~를 가지고 있었다 | 나에게는 ~가 있었다 |
| 영어식 수동 감각 표현 ("침묵이 내려앉았다" 남발) | 무엇이 조용해졌는지 쓴다 |

- 조각 문장("일 초. 이 초.")은 장면마다 많아야 한 번. 나머지는 완결된 문장으로 쓴다.
- 비유는 장면당 하나를 넘기지 않는다. 비유가 사실을 가리면 비유를 뺀다.
- 기울임(*…*)은 속마음이나 짧은 회상에만 쓰고, 그 회상이 언제의 일인지 알 수 있게 쓴다.

## 3. 명사는 한국어판을 따른다

- 9와 4분의 3 승강장 (9와 3/4 ✗)
- 미스터리 부서 (신비부 ✗)
- 그 밖의 고유명사는 확인될 때까지 지금 표기를 유지한다. 확인이 필요한 목록은 `docs/GLOSSARY.md`.

## 4. 그대로 지키는 것

- 1인칭("나"), 과거형 서술. 나의 성격은 설명하지 않는다.
- 이벤트 id, 선택지 구조, needs / cost / fx / next, 갈림길 tie·loosen·cut, 6월 준비 flag는 바꾸지 않는다.
- 길이는 늘어나도 된다(친절해지는 만큼). 다만 한 사건의 본문은 화면 두세 번 스크롤을 넘지 않게.
